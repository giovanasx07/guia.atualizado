# Meu Portfólio

## Feature JavaScript
Alternância de tema claro/escuro. A escolha do visitante fica salva
e é mantida ao recarregar a página ou navegar entre as páginas.

## Como testar
1. Abra o site e clique em "Alternar tema".
2. Recarregue a página: o tema deve continuar o mesmo.
3. Abra o DevTools (F12) → Application → Local Storage.

## Dados persistidos
- `tema`: "claro" ou "escuro"
